Date: 8.27.26 - Subject: Git and GitHub

    This week I learned more about how Git and GitHub work together. Git keeps track of changes to files on my computer, while GitHub stores a remote copy of my repository online.

    I also learned how to clone a repository, add files, commit changes, and push those changes to GitHub. I am still getting used to the different Git commands, but I understand the process better now and know how to check which files are being tracked.
