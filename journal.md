Date 09.11.2026 - Subject: User Stories

    This week I learned more about user stories and how they are used when developing software. Instead of only thinking about the programming side, user stories help us think about what the person using the program actually wants to do.

    For our YouFace project, we started making user stories using the “As a user, I want, so that” format. Some of the ideas we came up with included having credits, usernames, and eventually being able to play games against other people. This helped us think more about what features our project should have.

Date: 09.18.2026 - Subject: Git Branches and Team Development

    This week I learned more about using Git branches while working on a team project. Branches allow each person to work on different parts of the project without immediately changing the main version of the program.

    I practiced creating branches, switching between branches, pulling changes from GitHub, and checking the status of my repository. I am starting to understand why branches are useful when multiple people are working on the same project at the same time.

Date: 09.25.2026 - Subject: Flow Diagrams

    This week I learned about flow diagrams and how they can be used to show the steps a user follows when using an application. We used draw.io to create diagrams with different shapes for actions, decisions, and the direction the user moves through the program.

    For my flow diagram, I worked on the process of playing Blackjack in our YouFace casino project. I had to think about the different choices the player can make, such as hitting or standing, and what happens depending on the result. This helped me think more about the program from the user's point of view instead of only thinking about the code.
